Rex

面向 macOS 的原生桌面浏览器。垂直标签页、工作空间、双页面分屏，以及默认开启的隐私保护。

v1.0.0 build 1001 macOS 14+ Apple Silicon CEF 151 / Chromium 151 AGPL-3.0
在 GitHub 上查看 了解特性

主要特性

围绕真实使用场景构建，不追求功能堆砌。

🪟

原生 macOS 界面

浏览器外壳、导航、标签页、下载、对话框、设置与扩展管理均由 SwiftUI 与 AppKit 呈现。

⚡

Chromium 兼容能力

CEF 151 负责网页渲染、网络、开发者工具与扩展 API。本地源码编译，开启 H.264/AAC/HEVC 编解码器。

🗂️

垂直标签页与工作空间

按场景组织浏览会话，避免大量标签页挤在横向栏中。悬停即可查看标题和地址。

⬜

双页面分屏

在同一个窗口内并排浏览两个页面，比例可调，支持页面交换。

🛡️

隐私盾牌

清理追踪参数、尝试升级 HTTPS、拦截精选请求域名并限制第三方 Cookie。

🧩

扩展管理

通过原生 rex://extensions 界面安装、更新、启停、配置和移除 Chromium 扩展。

⏸️

标签管理

固定、分组、归档、自动休眠空闲标签页释放内存，恢复关闭的标签页。

💾

会话恢复

自动保存和恢复窗口、标签页、分屏组合与工作空间状态，重启后继续浏览。

🚫

不包含 AI 功能

不提供聊天、网页总结、推荐或自动浏览能力。把浏览交还给你。

技术架构

四层分工：应用外壳、网页运行时、桥接层与持久化层。

层级 技术 职责
应用外壳 SwiftUI + AppKit 窗口管理、标签列表、工具栏、设置面板、下载管理与文件选择
网页运行时 CEF 151 / Chromium 151 网页渲染、网络栈、V8 引擎、Blink、扩展 API、开发者工具、GPU 合成
CEF 桥接层 Objective-C++ 浏览器生命周期、多进程 Helper、扩展运行时对账与 DevTools 管道
持久化层 SQLite + Swift 标签会话、浏览历史、收藏夹、下载记录、网站权限与隐私策略
隐私引擎 C++ 域名目录拦截、请求分类、HTTPS 升级与追踪参数清理

系统要求与构建

从源码构建 Rex，需要完整的 Xcode 工具链与 CEF 依赖。

系统要求

  • macOS 14 或更高版本
  • 仅支持 Apple Silicon（arm64），不支持 Intel Mac
  • 安装带 macOS SDK 的 Xcode
  • 完整 Chromium 构建需要 XcodeGen、CMake 和 Ninja

构建步骤

Scripts/fetch-cef.sh Scripts/build-cef-runtime.sh xcodegen generate --spec project.yml

产物位于 Dist/Rex.app 与对应 zip 包。ad-hoc 签名仅满足 macOS 嵌套代码结构要求，不是 Developer ID 签名或公证版本。
