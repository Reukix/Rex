# Rex v0.9.0

发布日期：2026-07-27 · 渠道：beta · 构建：900

## 新标签页

- 最近访问和收藏网站放入等宽等高的双列区域，内容数量不再改变外框尺寸。
- 快捷操作和站点区域会在窄窗口或左右分屏中自适应换列，不再横向裁切或形成多层滚动捕获。
- 问候区显示当前 Google、Bing、DuckDuckGo、Brave Search 或 Ecosia 的本地品牌图标。
- 「新增」按钮打开原生表单，输入名称与网址后经规范化和校验再加入收藏网站。
- 所有普通窗口订阅同一个收藏仓库；写盘成功后才同步新增或移除，避免多窗口和启动恢复时覆盖数据。隐私窗口保持隔离。

## 版本与菜单

- 关于 Rex 补齐版本、构建、Chromium、CEF、arm64 架构、发布渠道、功能状态和已知限制。
- 应用主菜单与常用系统命令使用中文标题，保留原有键盘快捷键和系统角色。
- 同版本不同构建的发布记录使用「版本 + 构建号」身份；菜单本地化只处理明确的系统命令，不改动态窗口、工作空间或第三方服务标题。

## Rex 扩展商店

- 扩展页提供 Rex 品牌的 Chrome Web Store 扩展目录、搜索、分类和官方详情页入口。
- 扩展条目仅指向 Chrome Web Store 官方页面，Rex 不抓取、镜像或重新分发 CRX。
- 本地未打包扩展支持 `manifest.json`、本地化名称、图标与权限校验，以及受管副本导入、更新回滚、Finder 定位和移除。
- 导入拒绝包内符号链接，并限制文件数、总大小与元数据大小；管理目录与包身份在删除前重新校验，避免越界移动或删除。
- 当前 CEF 150 最小发行包没有 `CefExtension` / `LoadExtension` API，因此不声称支持 Chrome Web Store 直接安装、更新或完整 Manifest V3 运行时。
- 运行时不可用时不显示没有实际效果的启用开关；接近 256 MB 或 10,000 文件上限的大型本地包仍可能在导入时短暂阻塞界面。

## 已知限制

- 本地扩展的页面脚本、service worker 和 Chrome 扩展 API 尚不会在 Rex 中执行。
