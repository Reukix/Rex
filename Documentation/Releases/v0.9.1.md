## Chrome Web Store 直接安装

扩展页现在提供两种商店安装入口：

1. 在 Rex 精选目录点击「直接安装」。
2. 粘贴任意官方 Chrome Web Store 详情链接或 32 位扩展 ID。

安装链路依次执行：

1. 仅从 Google 官方更新主机发起 HTTPS 下载，并限制重定向主机与 256 MB 下载大小。
2. 解析 CRX2/CRX3，验证目标扩展 ID、公钥身份和 RSA/ECDSA 签名。
3. 解析 ZIP 中央目录，拒绝 ZIP64、多卷、加密、不支持的压缩方式、路径穿越、重复路径、符号链接和大小/文件数超限。
4. 校验每个文件的 CRC32 后解包到一次性暂存目录。
5. 使用原有事务式受管导入更新扩展目录，并持久化商店 ID 与安装来源。

相同扩展 ID 的再次安装会更新原包，并保留安装时间和启用偏好。失败时一次性暂存目录会被清理，旧包保持可恢复状态。

## CEF 包

CEF 锁文件由 minimal 切换为同版本官方 standard ARM64 发行包：

- 官方 SHA-1：`ae4a49d31fe61d4e0dc55050449cf967b7549ba0`
- SHA-256：`57f58530234f5b2a24f02479fdbc92b50aa5f94f7a66e32251cb71571284fad1`

standard 包补齐 Debug Framework 与官方示例源码，但它的 Release Framework 与 minimal 具有相同运行能力。CEF 150 在 macOS 中只要使用原生父 NSView，就会强制使用 Alloy runtime；因此 v0.9.1 的“直接安装”是可信下载、验证和包管理，已安装扩展仍不会执行页面脚本、service worker 或 Chrome API。

## 已知限制

- 商店扩展尚不自动检查或安装更新，可通过相同链接或 ID 手动重新安装。
- 已安装扩展暂不执行代码；后续可执行子集需要独立的权限审核与 macOS 宿主方案。
- Developer ID 签名、公证与应用自动更新尚未完成。
