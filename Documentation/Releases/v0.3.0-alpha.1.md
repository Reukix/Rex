# v0.3.0-alpha.1 版本功能报告

发布日期：2026-07-23

CEF 版本：150.0.14+g7c1aa68+chromium-150.0.7871.129  
Chromium 版本：150.0.7871.129

架构：Apple Silicon arm64 only  
发布通道：Alpha

## 本版目标

把 v0.2 的 JSON 会话基础推进为 SQLite 持久化，并完成标签组织、浏览资料库和多窗口会话恢复的基础工作流。

## 完成功能

- SQLite 保存窗口会话、空间、标签、分组、当前选择和分屏状态。
- 旧版 schema 1 JSON 会话的一次性迁移；SQLite 快照读取会校验版本和选择有效性。
- 标签搜索、固定、分组折叠、跨空间移动、自动休眠和归档恢复。
- 历史、收藏和下载资料库的查询、保存和删除基础能力。
- CEF 下载事件桥接，包含下载 ID、URL、文件名、字节数、状态和创建时间。
- 多窗口 UUID 会话恢复；当前窗口命令通过 focused object 路由到活跃窗口。

## 构建入口

依次运行 `Scripts/fetch-cef.sh`、`Scripts/build-cef-runtime.sh`、`xcodegen generate`，然后在完整 Xcode 中打开 `Rex.xcodeproj`。Swift Package 构建覆盖领域模型、SwiftUI 预览、SQLite 和版本门禁；真实 Chromium 构建使用生成的 Xcode 工程。

## 测试情况

- `swift build`：通过。
- `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test`：10 个测试全部通过。
- `RexReleaseValidator`：通过，版本、功能数据、发布数据和 v0.3 报告一致。
- CEF Objective-C++ bridge：通过 CMake 增量构建，下载 handler 编译并链接成功。
- `xcodegen generate`：通过，新增资料库 SwiftUI 文件已纳入生成工程。

## 已知限制

- 本地 arm64 Release 仍使用 ad-hoc 签名；Developer ID 签名、公证与自动更新属于正式发布阶段。
- v0.3 的分屏创建通过标签操作菜单完成；生产级四向拖放、热区预览和组合保存留待 v0.4。
- 下载目前记录 CEF 状态并由系统保存对话框选择位置，尚未提供下载项清理、打开文件和断点续传。
- 内容拦截、第三方 Cookie 策略、权限中心和隐私窗口隔离留待 v0.5。

## 回退

删除 `~/Library/Application Support/Rex/Browser.sqlite` 可重置 v0.3 浏览器会话、历史、收藏和下载记录。旧的 `~/Library/Application Support/Rex/Session/session-v1.json` 会在首次打开 SQLite 时尝试一次性迁移。
