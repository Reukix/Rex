# v0.2.0-alpha.1 版本功能报告

发布日期：2026-07-23  
构建编号：201  
CEF 版本：150.0.14+g7c1aa68+chromium-150.0.7871.129  
Chromium 版本：150.0.7871.129  
macOS 最低版本：14.0  
架构：Apple Silicon arm64 only  
发布通道：Alpha

## 本版目标

将 v0.1 的界面原型推进为真实 Chromium 集成基础：获得可重复下载和验证的 CEF runtime，编译 Swift/Objective-C++ 边界、沙箱 Helper 和页面事件管线，并保存浏览会话。

## 完成功能

- CEF ARM64 锁文件、下载、SHA-1/SHA-256 和架构校验。
- 214 个 CEF C++ wrapper 源文件的 Release 编译。
- Objective-C++ runtime、外部消息泵和 `RexApplication` Cocoa 集成。
- 稳定复用的 CEF `NSView` 标签宿主，后台切换不会主动销毁实例。
- 五类 Helper app bundle 的生成和 CEF framework 版本化嵌入。
- Swift `ChromiumBrowserEngine` 命令/事件适配。
- URL、标题、进度、历史能力与 renderer 崩溃状态同步。
- 标签、空间与分屏会话原子持久化。

## 构建入口

依次运行 `Scripts/fetch-cef.sh`、`Scripts/build-cef-runtime.sh`、`xcodegen generate`，然后在完整 Xcode 16+ 中打开 `Rex.xcodeproj`。Swift Package 构建不包含 CEF，仅用于界面和领域逻辑验证。

## 安全变化

- CEF 动态库不直接链接，由官方 `CefScopedLibraryLoader` 从应用包加载。
- Helper 初始化 `CefScopedSandboxContext`，主进程保持 `no_sandbox = false`。
- Swift 只可调用闭合的导航命令集，不暴露任意 JavaScript 或通用原生调用。
- CEF 及五个 Helper 在嵌入阶段分别签名；外层 Rex.app 由 Xcode 最后签名。

## 已知问题

- 当前机器没有 Developer ID 证书；本地 Release 关闭 Hardened Runtime 进行 ad-hoc 测试，正式分发必须使用同一团队证书签名全部嵌套代码并完成公证。
- 权限、下载、favicon、音频状态和内容拦截回调未接入。
- 会话模型尚未提供数据库迁移，只支持 schema v1 JSON。

## 回退

删除 `~/Library/Application Support/Rex/Session/session-v1.json` 可重置会话；删除 `Vendor/CEF` 后重新运行下载脚本可恢复固定 runtime。v0.2 不兼容 Intel 架构。
