# v0.4.0-alpha.1 版本功能报告

发布日期：2026-07-23

CEF 版本：150.0.14+g7c1aa68+chromium-150.0.7871.129  
Chromium 版本：150.0.7871.129  
macOS 最低版本：14.0  
架构：Apple Silicon arm64 only  
发布通道：Alpha

## 本版目标

把 v0.3 的双页面分屏原型推进为完整工作流：通过四向拖放创建左右或上下布局，稳定管理页面焦点与交换，并保存可跨空间恢复的分屏组合。

## 完成功能

- 标签行、折叠标签和收藏 favicon 均可作为拖拽源。
- 内容区左、右、上、下 24% 边缘热区提供方向图标和投放预览，中央区域不创建分屏。
- 支持同空间创建/替换 pane，以及从其他空间迁移标签后创建分屏。
- 页面交换保留原网页焦点，焦点切换同步标签选择、地址栏、最近访问时间和页面优先级。
- 分屏比例限制为 25%–75%；比例调整、方向切换和页面交换复用原有 WebKit/CEF 页面实例。
- 保存、恢复和删除命名分屏组合，记录空间、页面、方向、比例、焦点和最近使用时间。
- 会话 schema v3 保存空间级活动分屏、pane 导航状态、缩放和静音状态，并兼容 v2 快照。

## 构建入口

依次运行 `Scripts/fetch-cef.sh`、`Scripts/build-cef-runtime.sh`、`xcodegen generate`，然后在完整 Xcode 中打开 `Rex.xcodeproj`。Swift Package 构建继续提供 WebKit 设计预览；真实 Chromium 构建由生成的 Xcode 工程提供。

## 测试情况

- `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test`：20 个测试全部通过。
- 测试覆盖四向坐标解析、比例边界、v2/v3 Codable、交换焦点、方向切换、跨空间拖放、分屏组合、自动休眠与音频保护、页面实例复用。
- 完整 CEF、Xcode Debug/Release 和发布门禁结果以本次构建验证为准。

## 已知限制

- 一次只支持两个页面，不提供三栏或四宫格布局。
- 组合中的标签若已关闭、已归档或移动到其他空间，组合会拒绝恢复。
- 滚动位置字段已纳入 pane 快照，但 CEF 当前没有暴露实时滚动位置事件，因此本版保存默认值。
- Developer ID 签名、公证与自动更新仍属于正式发布阶段。
- 内容拦截、第三方 Cookie 策略、权限中心和隔离隐私窗口留待 v0.5，本版未提前实现或标记完成。

## 回退

v0.4 沿用 `~/Library/Application Support/Rex/Browser.sqlite`。删除该文件可重置所有窗口会话、分屏组合、历史、收藏和下载记录；旧 v2 快照会在读取时把新增分屏集合初始化为空数组。
