# Rex v0.8.1

发布日期：2026-07-27 · 渠道：beta · 构建：810

## 版本摘要

本版本补齐资料库历史清理，修复收藏和下载空状态的顶部留白，并将 macOS 标题栏恢复为红黄绿按钮右侧的紧凑单导航卡；点击导航栏首项的指标可进入逐网页性能详情。同时按源码审计结果公开隐私盾牌完整目录，明确现有能力与未实现边界。

## 历史与资料库

- 历史记录页新增「删除浏览数据」菜单，支持永久删除过去 1 小时、过去 24 小时、过去 7 天或所有时间的浏览历史。
- 时间范围删除包含 cutoff 边界；「所有时间」删除全部历史记录。
- 删除前显示所选范围的确认提示，并明确收藏和下载记录不会被删除。
- 内存历史与当前搜索结果立即刷新，同时异步写入 SQLite；数据库失败会进入现有错误状态。
- 收藏和下载空状态占满标题栏下方剩余内容区，不再把资料库标题栏推到窗口中部。

## 原生窗口标题栏

- AppKit 为主窗口启用透明全尺寸内容标题栏、隐藏系统标题并移除标题分隔线。
- 窗口协调器将 macOS 标准红黄绿按钮整体下移 8 pt，使其与导航卡垂直居中，再根据真实 frame 计算按钮尾缘，并把独立的全屏状态同步给 SwiftUI；重复刷新不会累积偏移，全屏时恢复系统位置。
- 普通窗口和全屏均使用 50 pt 标题栏槽内的单张 44 pt 导航卡。普通窗口从红黄绿按钮尾缘加 8 pt 净空后开始，全屏时使用 8 pt 左边距。
- 内存/CPU 指标是导航栏首项；关闭性能监测时直接省略指标。红黄绿按钮周围的无控件区域保留给窗口拖动，不再添加重复页面标题或装饰内容。

## 性能监测详情

- 点击标题栏内存或 CPU 指标打开 760 × 520 pt 原生详情页，显示 Rex 总内存、总 CPU、标签页数量和最近更新时间。
- 每个标签页使用独立卡片，按标签页顺序稳定显示 favicon、标题、站点、当前/后台/分屏/休眠/冻结/归档/崩溃状态、内存和 CPU；不使用排序切换或行分隔线。
- Rex 总量继续由 Darwin proc_pid_rusage 遍历主进程和全部 Helper 进程得到。网页行使用 CEF 150 CefTaskManager::GetTaskIdForBrowserId 与 GetTaskInfo 读取标签关联任务，不用总量平均估算。
- CEF 任务管理器首轮约 2 秒刷新完成前保持加载；休眠、归档或尚未提供任务数据时显示“—”，不会删除页面行。CEF 公共 API 不公开 renderer PID，无法可靠标记共享 renderer；可能出现的重复进程级数值不能跨行相加。
- 监测器按界面订阅引用计数启停；最后一个工具栏或详情页订阅结束后释放 CefTaskManager，不继续进行后台任务采样。
- GPU、Worker、Utility 和站点隔离子框架无法可靠归属到单个标签，只包含在 Rex 总量中，不分摊给网页。

## 隐私盾牌如何工作

当前实现由三个不同层次组成：

1. **Swift 顶层导航**：`PrivacyURLPolicy` 清理已知追踪参数，并对符合条件的 HTTP 地址尝试 HTTPS。该策略用于地址栏导航和 Rex 接管的弹窗导航，不改写网页自行发起的 CEF 子资源。
2. **CEF 子资源请求**：`RexPrivacyEngine.cpp` 编译内置 45 个广告、41 个追踪、10 个指纹和 8 个社交目录条目。`OnBeforeResourceLoad` 在 IO 线程分类请求，命中后返回 `RV_CANCEL`，再把分类和域名回传为 blocked event，供标签页统计聚合。
3. **第三方 Cookie**：CEF RequestContext/profile 使用全局 `profile.cookie_controls_mode` 设置限制第三方 Cookie；`CanSendCookie` 和 `CanSaveCookie` 不逐请求取消 Cookie。

保护级别的实际语义：

- **标准**：匹配第三方广告和追踪目录；指纹保护默认开启，所以标准模式也会匹配第三方已知指纹服务。
- **严格**：包含标准能力，并追加第三方社交目录。
- **自定义**：映射为 CEF `aggressive`；广告和追踪目录可匹配第一方请求，同时对第三方请求启用有限路径启发式。

主框架导航永不由 CEF 目录层取消；无法判断第一方时放行。第一方判断是有限的 registrable-domain 启发式与少量常见二级后缀表，并非完整 PSL/eTLD+1。关闭单个标签页盾牌不会关闭 profile 级 Cookie 限制。拦截统计按标签累计并持久化，不会在每次导航后自动清零。

当前没有恶意网站检测、Safe Browsing、自定义规则、EasyList、元素隐藏、在线目录更新、通用 Canvas/WebGL 指纹随机化或完整 brave-core。

全部 104 条请求规则、3 条 `host + path` 规则、重复项及分类优先级见[隐私盾牌内置请求目录](../PrivacyDomainCatalog.md)。

## 其他界面变化

- 标签页右键菜单不再显示「关闭其他标签页」和「关闭右侧标签页」。
- 分屏继续只支持左右布局，并继续通过标签页右键菜单选择左右位置；不恢复拖放分屏或网页蓝色选择框。

## 已知限制

- 当前 Debug 包不包含 Developer ID 分发签名或公证。
- 域名目录随应用编译，在线更新尚未接入。
- 第三方 Cookie 限制与单标签盾牌开关不是同一作用域。
- CEF 网页指标是标签关联 renderer 的进程级快照；共享 renderer 的重复值不能相加，且不包含可单独归属的 GPU/Worker 明细。
