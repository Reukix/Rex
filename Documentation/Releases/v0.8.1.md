# Rex v0.8.1

发布日期：2026-07-27 · 渠道：beta · 构建：810

## 版本摘要

本版本补齐资料库历史清理，修复收藏和下载空状态的顶部留白，并把主导航栏移入 macOS 标题栏、放在红黄绿窗口按钮右侧。同时按源码审计结果更新隐私盾牌说明，明确现有能力与未实现边界。

## 历史与资料库

- 历史记录页新增「删除浏览数据」菜单，支持永久删除过去 1 小时、过去 24 小时、过去 7 天或所有时间的浏览历史。
- 时间范围删除包含 cutoff 边界；「所有时间」删除全部历史记录。
- 删除前显示所选范围的确认提示，并明确收藏和下载记录不会被删除。
- 内存历史与当前搜索结果立即刷新，同时异步写入 SQLite；数据库失败会进入现有错误状态。
- 收藏和下载空状态占满标题栏下方剩余内容区，不再把资料库标题栏推到窗口中部。

## 原生窗口标题栏

- AppKit 为主窗口启用透明全尺寸内容标题栏、隐藏系统标题并移除标题分隔线。
- 工具栏根据 macOS 标准红黄绿按钮的真实 frame 动态计算左侧净空，因此导航控件从窗口按钮右侧开始。
- SwiftUI 顶栏延伸进顶部 safe area；全屏时窗口按钮消失，左侧净空恢复为普通 8 pt。

## 隐私盾牌如何工作

当前实现由三个不同层次组成：

1. **Swift 顶层导航**：`PrivacyURLPolicy` 清理已知追踪参数，并对符合条件的 HTTP 地址尝试 HTTPS。该策略用于地址栏导航和 Rex 接管的弹窗导航，不改写网页自行发起的 CEF 子资源。
2. **CEF 子资源请求**：`RexPrivacyEngine.cpp` 编译内置 45 个广告、41 个追踪、10 个指纹和 8 个社交目录条目。`OnBeforeResourceLoad` 在 IO 线程分类请求，命中后返回 `RV_CANCEL`，再把分类和域名回传为 blocked event，供标签页统计聚合。
3. **第三方 Cookie**：CEF RequestContext/profile 使用全局 `profile.cookie_controls_mode` 设置限制第三方 Cookie；`CanSendCookie` 和 `CanSaveCookie` 不逐请求取消 Cookie。

保护级别的实际语义：

- **标准**：匹配第三方广告和追踪目录；指纹保护默认开启，所以标准模式也会匹配第三方已知指纹服务。
- **严格**：包含标准能力，并追加第三方社交目录。
- **自定义**：映射为 CEF `aggressive`；广告和追踪目录可匹配第一方请求，同时对第三方请求启用有限路径启发式。

主框架导航永不由 CEF 目录层取消；无法判断第一方时放行。第一方判断是有限的 registrable-domain 启发式与少量常见二级后缀表，并非完整 PSL/eTLD+1。关闭单个标签页盾牌不会关闭 profile 级 Cookie 限制。拦截统计按标签累计并持久化，不会在每次导航后自动清零。

当前没有恶意网站检测、Safe Browsing、自定义规则、EasyList、元素隐藏、在线目录更新、通用 Canvas/WebGL 指纹随机化或完整 brave-core。

## 其他界面变化

- 标签页右键菜单不再显示「关闭其他标签页」和「关闭右侧标签页」。
- 分屏继续只支持左右布局，并继续通过标签页右键菜单选择左右位置；不恢复拖放分屏或网页蓝色选择框。
