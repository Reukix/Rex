# v0.1.0-alpha.1 版本功能报告

发布日期：2026-07-23  
构建编号：101  
Chromium 版本：尚未集成  
macOS 最低版本：14.0  
发布通道：Alpha

## 本版目标

将 1861 行产品提示转化为可审阅的产品/技术基线和可编译的 SwiftUI 原型，验证主窗口、垂直标签、工作空间、分屏与隐私盾牌的核心层级。

## 完成功能

- 原生主窗口、紧凑地址栏与可折叠液态玻璃侧栏。
- 标签选择/新建、工作空间切换和状态展示。
- 左右/上下分屏、焦点、比例与交换交互。
- 隐私盾牌站点报告原型。
- 完整核心模型、BrowserEngine 协议和预览引擎。
- CHANGELOG、FEATURES、ROADMAP、JSON 数据与构建校验。

## 使用入口

运行 `swift run Rex`。工具栏分屏按钮创建/关闭双页；方向按钮切换布局；分隔条可调整比例；交换按钮交换两页。地址栏右侧盾牌打开站点报告。

## 界面变化

这是首个界面版本。玻璃只用于工具栏、侧栏、标签选中态和浮层，网页画布保持不透明。颜色、图标和文字共同表达状态。

## 隐私变化

目前为报告和配置交互原型，没有声明真实网络拦截。所有演示数字标注为样例状态。

## 性能变化

分屏比例由容器布局调整；列表使用 LazyVStack。生产 Chromium 的 frame 复用和多进程指标待 v0.2 实现。

## 测试情况

- 模型、分屏状态和版本数据的 Swift Testing 单元测试随工程提供。
- 在 Apple Silicon、macOS 27 SDK、Swift 6.4 Command Line Tools 环境执行 `swift build --disable-sandbox`，构建与版本门禁通过。
- 当前机器未安装完整 Xcode，缺少 `TestingMacros`/XCTest host plugin，因此本地 `swift test` 无法启动；测试需在完整 Xcode 环境或 CI 执行。这是工具链限制，不计为测试通过。

## 已知问题

- WebKit 仅为设计预览面，不能代表最终 Chromium 行为。
- 尚未接入持久化、拖放、真实隐私拦截或网站权限。
- 本项目后续明确仅支持 Apple Silicon；本版未进行旧版 macOS、签名或公证验证。

## 升级与回退

本版尚不写入用户浏览数据。回退只需退出并删除构建产物；不存在数据迁移。
