# Rex v0.9.5

发布日期：2026-07-28<br>
构建号：950<br>
通道：Beta<br>
架构：Apple Silicon（arm64）<br>
内核：Chromium 150.0.7871.129 / CEF 150.0.14

## 概要

v0.9.5 让隐私盾牌恢复 Safari 版本的按网站设置方式，并修复扩展小型面板的两个真实问题：面板此前没有来源网页的当前标签上下文，因此 uBlock Origin Lite 等扩展无法识别网站或保存过滤模式；在 `rex-extension` 页面再次点扩展按钮时，SwiftUI Popover 又可能沿 CEF `NSRemoteView` 的 AppKit 窗口排序路径崩溃。

## 主要变化

### 隐私盾牌

- 新增按 profile/host 唯一持久化的 `SitePrivacyPolicy`。
- 保护开关与级别立即同步所有同站标签，重启后继续复用。
- 网站选择不再修改工作空间默认级别；进入其他网站时应用其自身策略或原默认值。
- 隐私窗口只在内存中应用，不写入普通 profile。

### 扩展面板

- 静态 popup 的 `chrome.tabs.query({active:true,currentWindow:true})` 返回点击扩展按钮前的真实 HTTP(S) 来源标签。
- 在 `rex-extension://` 页面重新打开扩展时沿用最近有效网页来源，使扩展设置仍作用于目标网站。
- 工具栏扩展列表与 popup 改为独立 AppKit 浮窗，不再通过 SwiftUI `.popover` 和 `NSWindow.addChildWindow` 附着到 CEF 远程视图。
- 面板尺寸与关闭回调绑定当前会话 ID，旧回调不会关闭或改变后来打开的面板。

## 已知边界

- Rex 小型面板不是 Chromium 原生 action popup。v0.9.5 只为静态 popup 提供受控来源标签查询上下文，完整 `activeTab` 权限授予仍不支持。
- 未声明静态 `default_popup` 时的 `action.onClicked`、运行时 `action.setPopup` 动态变更仍不支持。
- 网站策略按精确主机名保存，尚未按完整 PSL/eTLD+1 合并子域。
- Developer ID 签名、公证与自动更新尚未完成。
