# v0.5.1-beta.1 版本功能报告

发布日期：2026-07-23  
构建编号：511  
CEF 版本：150.0.14+g7c1aa68+chromium-150.0.7871.129  
Chromium 版本：150.0.7871.129  
macOS 最低版本：14.0  
架构：Apple Silicon arm64 only  
发布通道：Beta

## 本版目标

把 v0.5.0 只能记录进度的下载资料库推进为可操作的下载管理器，同时保持工作空间设置、隐私窗口和旧 SQLite 数据兼容。

## 完成名单

- 下载任务可通过 CEF 活动回调取消。
- 失败或取消任务可沿用原记录 ID 和来源 URL 重试，避免重复记录。
- CEF 事件保存本地目标路径、中断原因、接收字节数和可选总字节数。
- 完成项可打开文件或在 Finder 中显示；终态记录可从 SQLite 删除。
- 下载目录按工作空间保存为安全作用域书签；未设置时继续使用 CEF 系统保存对话框。
- 自定义目录遇到同名文件时自动追加序号，不覆盖现有文件。
- 隐私窗口保留本次运行的内存下载状态，但不写入普通资料数据库。
- 修复启动时实时历史、收藏、下载和权限状态被随后完成的 SQLite 加载覆盖的竞态。
- 兼容不含 `destinationURL` 和 `errorDescription` 的旧下载记录。

## 未完成名单

- 原生文件选择器与上传流程。
- JavaScript alert、confirm、prompt 和 beforeunload 原生对话框。
- 网页全屏与窗口级全屏交互。
- 页面证书与安全状态详情。
- Renderer 崩溃恢复界面和恢复操作。
- 集中的应用设置中心。
- 下载内容校验、危险文件提示、批量清理和保留期限策略。
- Developer ID 签名、公证和自动更新。

## 已知问题

- v0.5.0 及更早的下载记录从未保存本地路径，因此升级后不能直接“打开文件”或“在 Finder 中显示”；新下载不受影响。
- 文件在下载完成后若被移动或删除，打开与 Finder 操作会提示路径已失效，但当前不会自动搜索新位置。
- 重试依赖当前窗口仍有可用 Chromium 标签页；页面实例尚未创建完成时，CEF 不会开始任务。
- 当前没有暂停/继续下载，也没有跨应用重启恢复未完成下载。
- CEF MVP 只承诺受控、经审核的扩展子集，不承诺完整 Chrome Web Store 兼容或 Google 账号同步。

## 测试与验证

- `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test`：39 个测试全部通过。
- `xcodebuild` 完整 CEF/Xcode arm64 Debug 构建通过。
- 测试覆盖旧下载记录解码、SQLite 删除、取消/重试命令、工作空间目录书签，以及启动实时事件合并。

## 回退

本版不升级 SQLite schema。新增下载字段位于 JSON payload 内，旧版本会忽略尚未写入的新记录字段；回退前仍建议备份 `~/Library/Application Support/Rex/Browser.sqlite`。下载目录书签保存在窗口会话的工作空间数据中。
