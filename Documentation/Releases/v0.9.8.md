# Rex v0.9.8 build 984 发布说明

日期：2026-08-01
通道：本地 Beta 候选
内核：CEF 150 / Chromium 150.0.7871.129

## 核心变化

v0.9.8 继续执行“Rex 可见 UI、Chromium 权威后端”。Chromium 独占下载请求、重定向、传输、落盘和生命周期，并提供 URL、原始 URL、文件名、MIME、大小、进度、路径和中断事实；Rex 只把这些事实映射到自有右侧下载模块和资料库。进度百分比优先取 Chromium `GetPercentComplete()`，未知时才根据 Chromium 回调中的字节数显示回退进度；状态、按钮可用性和终态同样只映射 Chromium 快照，未知状态不可操作，重试等待新的 Chromium 回调。Chromium 原生保存面板、下载按钮、完成气泡和开始动画均保持关闭，默认保存到 `~/Downloads/Rex`；新下载开始时自动弹出 Rex 浮层，同一任务的后续更新不会重复弹出。

Chromium 150 不再用 `DownloadBubble` feature flag 控制开始动画；Rex 随签名包内置固定 ID 的 MV3 控制扩展，调用官方 `chrome.downloads.setUiOptions({enabled: false})`，并在启动同步时启用隐私窗口访问。该扩展只关闭 Chromium 可见下载 UI，不参与下载传输或状态生成。

build 982 的崩溃报告确认 SwiftUI `NSPopover` 在下载自动弹出、站点信息或隐私盾牌打开时，会与 CEF `NSRemoteView` 子窗口同时进入 `NSWindow.addChildWindow` 排序，并在 macOS 27 的 `containingWindowWillOrderOnScreen` 路径抛出无法由 Swift 捕获的 AppKit 异常。build 983 将三个入口与扩展入口统一迁移到独立无边框 Rex `NSPanel`，继续使用原有 SwiftUI 内容和 Chromium 状态映射，但不再附着到 Chromium 子窗口；源码门禁禁止工具栏重新使用 `.popover`。

build 984 修复下载记录的恢复边界：上次运行遗留的未完成快照现在显示为“状态未知”并可以删除，不再把不存在的 Chromium 任务伪装成可取消下载；资料库新增清空所有非活动下载记录的按钮。操作只删除 Rex 的 SQLite 记录，不删除磁盘文件，当前仍由 Chromium 处理的任务保留。

Rex 不再通过 `Pause/Resume` 或下载批准事件介入 Chromium 生命周期。隐私窗口仍不把下载写入普通资料库、历史或会话，但保存的文件会留在磁盘；当前版本不额外提供落盘确认。

站点归属从少量手写后缀升级为 Mozilla Public Suffix List `2026-07-25_14-20-03_UTC` 官方快照。Swift 站点策略和 CEF 第一方/第三方分类读取同一次安全资源选择，覆盖 ICANN、private suffix、通配、例外、IDN、localhost 和 IP。旧精确主机策略按 eTLD+1 迁移，冲突保留最近修改并原子替换。

`V098-CATALOG-01` 已实现：隐私目录从 C++ 硬编码迁移为可审计 JSON 基线，并与 PSL 一起使用 Ed25519 签名 manifest、HTTPS 同源下载、大小/哈希/格式检查、单调 sequence、原子安装、候选启动验证、last-known-good、失败回退、吊销、降级拒绝与 kill switch。仓库没有生产端点或公钥映射，因此默认不联网并继续使用 bundle 基线。

## 准确边界

- 隐私统计是当前标签整个会话的累计值，不是最近一次文档加载。
- 第三方 Cookie 是应用级共享 Chromium 设置，同步应用到普通及隐私 RequestContext，不是按网站开关。
- “已知指纹服务”表示网络目录匹配，不是 Canvas/WebGL/Audio 随机化。
- 恶意网站检测选择为当前明确不提供：Rex 不上传访问 URL 给第三方 provider，也不使用 Safe Browsing 文案暗示不存在的能力。
- 普通下载没有 Rex 自建的信誉、恶意内容、代码签名或 quarantine 公证扫描。

- `V098-CATALOG-01` 与 PSL 在线策略的客户端、配置映射和故障注入测试完成；上线还需提供 HTTPS 端点、32-byte Ed25519 公钥和仓库外私钥发布流程。

- Developer ID 模式、嵌套同团队/Hardened Runtime、stapler、Gatekeeper、独立签名更新清单与精确回退包门禁已落到脚本；当前只有免费个人团队 Apple Development 证书，无法通过 Developer ID 与 Apple 公证，正式自动替换/失败演练仍保持阻塞。
