# v0.5.0-beta.1 版本功能报告

发布日期：2026-07-23  
构建编号：501  
CEF 版本：150.0.14+g7c1aa68+chromium-150.0.7871.129  
Chromium 版本：150.0.7871.129  
macOS 最低版本：14.0  
架构：Apple Silicon arm64 only  
发布通道：Beta

## 本版目标

完成 Rex MVP 的隐私与权限闭环，并在不破坏垂直标签、分屏和 profile 隔离的前提下补齐高频 Chrome 浏览行为。

## 完成功能

- HTTPS 升级、已知追踪参数清理、基础广告/追踪资源拦截和第三方 Cookie 阻止。
- 隐私盾牌展示真实页面拦截分类、HTTPS 升级、参数清理和站点权限。
- 权限决定按 profile、顶层来源、请求来源和权限类型保存，支持每次询问、仅本次、始终允许/阻止和关闭标签撤销。
- `⇧⌘N` 创建独立内存 RequestContext 的隐私窗口，不恢复会话，不写历史、收藏、下载和权限数据库。
- CEF 原生右键菜单及 Cocoa 事件作用域修复。
- Chrome 风格地址、导航、页面查找、缩放、标签切换、恢复关闭标签和 DevTools 快捷键。
- 复制标签、静音、favicon、音频状态、打印，以及网页弹窗转 Rex 管理标签。
- `⌘1…9` 直达标签、`⌃1…9` 直达工作空间和分屏键盘操作。

## 构建入口

运行 `xcodegen generate` 后，使用 `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project Rex.xcodeproj -scheme Rex -configuration Debug -derivedDataPath .build/xcode-debug build CODE_SIGNING_ALLOWED=NO` 构建真实 Chromium 产物。UI 回归必须使用 `.build/xcode-debug/Build/Products/Debug/Rex.app`。

## 测试情况

- `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test`：36 个测试全部通过。
- 完整 CEF/Xcode Debug 构建通过。
- UI 回归覆盖网页内容区、地址与查找快捷键、隐私窗口、权限提示、权限中心及 Chromium 原生右键菜单。

## 已知限制

- 下载管理器仍缺少取消、重试、打开文件和目标目录设置。
- 原生文件选择、JavaScript 对话框、全屏窗口、页面安全详情和崩溃恢复界面继续安排在 v0.5.x。
- favicon 由 CEF 在当前 profile 内下载，Swift 只保留有界内存 PNG 缓存，不创建独立的 URLSession 缓存。
- CEF MVP 只支持受控、经审核的扩展子集，不承诺 Chrome Web Store 完整兼容。
- Google 账号同步不是 Rex 首发目标。
- Developer ID 签名、公证与自动更新仍属于正式发布阶段。

## 回退

v0.5 沿用 `~/Library/Application Support/Rex/Browser.sqlite` 并把 schema 升到 v3。回退到 v0.4 前应备份该数据库；隐私窗口没有持久化数据，不需要迁移。
