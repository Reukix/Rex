# Rex v0.8.0-beta.1

发布日期：2026-07-26 · 渠道：beta · 构建：801

## 版本摘要

移除 EasyList 引擎（拦截效果不佳），隐私盾牌改用可预期的精选域名目录方案；分屏仅保留左右方向，并改为通过标签页右键菜单明确选择左右位置。

## 隐私盾牌：域名目录方案（任务 1 & 2）

v0.7.0 的 EasyList 快照引擎实际拦截效果不佳（保守的规则丢弃策略削弱了覆盖面，快照也无法在线更新），本版本整体移除并改用精选域名目录：

- **移除**：`RexEasyListEngine.{h,cpp}`、`Resources/FilterLists/`（EasyList / EasyPrivacy / EasyList China，约 4.2 MB）、列表装载 API 与相关测试。
- **新方案**（`RexPrivacyEngine.cpp`）：
  - 标准级别：仅拦截**第三方**请求中命中内置广告/追踪域名目录的请求；精确域名匹配（含少量域名+路径条目），**不使用路径启发式**——这是对 build 605-607 误伤事故的直接约束。
  - 严格级别：追加指纹目录（受指纹保护开关控制）与社交组件目录。
  - 激进级别：才启用路径启发式与第一方匹配（明确的用户选择）。
  - 未知第一方一律按第一方处理，宁可漏拦不误拦；主框架导航永不拦截。
- **开关链路**：设置 › 隐私与安全 › 「拦截广告与追踪器」（`Rex.contentBlockingEnabled`，默认开启）→ `.setContentBlocking` 命令 → `setContentBlockingEnabled:` → C++ 原子开关，即时生效。每标签页盾牌开关与保护级别继续独立生效。
- 拦截统计沿既有 `blockedResource` 事件回流隐私盾牌与侧栏计数。

## 分屏重构（任务 3 & 4）

- **仅左右分屏**：删除上下分屏布局、工具栏「切换分屏方向」按钮与 ⌘⌥O 菜单命令;`SplitOrientation.vertical` 仅保留用于解码旧数据，所有恢复路径（会话、空间切换、分屏组合）强制转为左右。
- **标签页右键菜单分屏**：未分屏时可创建分屏或将其他标签放到左/右侧；已有分屏时可替换指定页面、将分屏成员换侧，或关闭分屏并保留该标签。
- **移除拖放与蓝框**：删除标签拖放分屏协议、网页半区投放预览和分屏页面蓝色焦点描边；分隔条拖动调节比例保持不变。
