# v0.5.2-beta.1 版本功能与完成报告

发布日期：2026-07-23  
构建编号：521  
CEF 版本：150.0.14+g7c1aa68+chromium-150.0.7871.129  
Chromium 版本：150.0.7871.129  
macOS 最低版本：14.0  
架构：Apple Silicon arm64 only  
发布通道：Beta

## 本版目标

先对 v0.5.1 的真实界面做基线测试，再参考 Chrome 的信息层级补齐 Rex 的页面右键菜单、标签页菜单、右上角主菜单和设置中心，并让地址栏可以使用用户选择的默认搜索引擎。

本报告中的“浏览器引擎”按需求语境实现为“默认搜索引擎”。Rex 的网页渲染内核仍固定为 CEF/Chromium，不会因选择 Google、Bing 或 DuckDuckGo 而更换。

## UI 基线测试

实现前使用 v0.5.1 CEF Debug 构建完成真实 UI 检查：

- 地址输入、页面加载、后退/前进状态和工具栏正常。
- 右上角“更多”菜单只有“版本与功能”和版本文本。
- 页面空白处右键菜单只有返回、前进、打印和网页源代码。
- 标签页菜单已有复制、静音、固定、收藏、分屏、移动、休眠、归档和关闭，但缺少重载与批量关闭。
- 没有设置中心，也无法选择默认搜索引擎。

## 完成名单

- 新增 Chrome 风格右上角主菜单，按组提供新标签页、新窗口、隐私窗口、历史、下载、书签、缩放、打印、页内查找、开发者工具、网站权限、版本功能和设置。
- 新增 `⌘,` 设置入口，并保留原生 macOS 菜单与快捷键行为。
- 新增 Chrome 风格设置中心，左侧包含常规、搜索引擎、隐私与安全、下载内容、外观和关于 Rex，顶部支持设置搜索。
- 新增 Google、Microsoft Bing、DuckDuckGo、Brave Search 和 Ecosia 五个默认搜索引擎。
- 搜索引擎偏好写入 `UserDefaults`，重启后保持；地址栏关键词和右键“搜索所选文本”统一使用当前选择。
- CEF 页面右键菜单会根据页面、链接、媒体、选中文本或可编辑区域动态组装。
- 页面菜单包含返回、前进、重新加载、保存页面、打印、复制页面地址、查看源代码和检查。
- 链接菜单包含新标签页打开、Rex 分屏打开、复制链接和链接另存为。
- 媒体菜单包含新标签页打开、媒体另存为和复制媒体地址。
- 选中文本支持复制与使用默认搜索引擎搜索。
- 可编辑区域支持拼写建议、撤销、重做、剪切、复制、粘贴、粘贴并匹配样式、删除和全选。
- 标签页菜单新增新建标签页、重新加载、关闭其他标签页和关闭右侧标签页。
- 资料库主菜单可直接定位到历史、下载或书签分类。
- 新增搜索 URL、偏好持久化、地址栏搜索、右键事件和批量关标签测试，Swift 回归从 39 项扩展到 44 项。

## 已知问题

- “保存页面…”当前使用 CEF 下载当前页面 URL 的回退能力，不是 Chrome 可同时保存 HTML 与资源目录的完整“网页另存为”。
- 自定义 CEF 菜单使用系统原生菜单外观，但自定义项目没有 Chrome 品牌图标；系统可能自动追加“服务”和“自动填充”子菜单。
- Google、Bing、DuckDuckGo 等是搜索服务选择，不会切换 Rex 固定的 Chromium 渲染内核，也不会更改 macOS 系统默认浏览器。
- 当前设置中心覆盖本版本相关的高频配置，不等同于 Chrome 全量设置；部分分类仍以状态说明和现有功能入口为主。
- 链接在分屏打开时受 Rex 双页面上限约束；已有分屏会按现有分屏生命周期规则重组。
- Gemini、AI 搜索、总结、推荐和自动操作属于 Rex 明确不规划的能力，因此没有照搬参考图中的 AI 菜单项。
- CEF MVP 只承诺受控、经审核的扩展子集，不承诺完整 Chrome Web Store 兼容或 Google 账号同步。

## 回退

本版不升级 SQLite schema。搜索引擎偏好只写入 `UserDefaults` 的 `Rex.defaultSearchEngine`，旧版会忽略该键；回退不会破坏会话数据库。回退前仍建议备份 `~/Library/Application Support/Rex/Browser.sqlite`。
