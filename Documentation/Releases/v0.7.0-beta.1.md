# Rex v0.7.0-beta.1

发布日期：2026-07-26 · 渠道：beta · 构建：701

## 版本摘要

以真实 EasyList 语义重新引入广告与追踪拦截并提供设置开关，性能层升级至 rex-thorium-hybrid-v1.3，站点信息弹窗支持证书与网站权限的弹窗内钻取详情页，并完成一轮 SwiftUI 明暗外观打磨。

## EasyList 内容拦截（任务 4）

v0.6.0 build 607 曾因自研域名目录规则过宽误伤站点资源而整体移除拦截路径。本版本改为实现真实 EasyList 过滤语法子集（`ChromiumBridge/Privacy/RexEasyListEngine.{h,cpp}`）：

- **规则来源**：打包 EasyList、EasyPrivacy、EasyList China 快照（2026-07-26，约 16 万行）到 `Sources/RexApp/Resources/FilterLists/`。
- **语义支持**：`||` 域名锚点、`|` 首尾锚点、`*` 通配、`^` 分隔符；`@@` 例外规则；`$domain=`（含 `~` 排除）、资源类型（script/image/stylesheet/xhr/subdocument/object/media/font/websocket/ping/other）、`$third-party`/`$~third-party`、`$important`、`@@…$document` 整页豁免。
- **防误伤原则**：无法忠实实现语义的规则（`$popup`、`$redirect=`、`$csp=`、`$removeparam=`、正则规则、`$match-case` 等）整条丢弃而不是近似执行；纯 cosmetic 作用域的例外规则不会退化成全站网络豁免；主框架导航永不拦截。
- **索引结构**：域名锚点规则按锚点域名分桶，其余按模式中有边界保证的最长 token 分桶（FNV-1a），IO 线程上按 URL token 查桶后做完整模式匹配。
- **线程模型**：规则在后台线程解析，不可变快照原子替换；`OnBeforeResourceLoad`（IO 线程）只读快照与 `@synchronized` 策略存储。
- **开关链路**：设置 › 隐私与安全 › 「启用 EasyList 规则」（`BrowserPreferences.easyListBlockingEnabled`，默认开启）→ BrowserStore Combine sink → `BrowserCommand.setContentBlocking` → `RexChromiumRuntime configureAdBlockEnabled:listPaths:` → 引擎原子开关，无需重启。每标签页的隐私盾牌开关与保护级别继续独立生效。
- **统计回路**：命中后按列表类别（EasyList/China → 广告，EasyPrivacy → 追踪器）经既有 `blockedResource` 事件进入隐私盾牌与侧栏计数。

## 性能层 v1.3（任务 1）

- raster 线程随逻辑核数自适应：≤8 核 4 线程、≤12 核 6 线程、更多 8 线程（原固定 4）。
- 显式 `--use-angle=metal`，GPU 进程不再探测旧 OpenGL 路径。
- ≤8 GiB 内存机型追加 `SpareRendererForSitePerProcess` 禁用，省去常驻备用渲染进程（约 150 MB）。
- 继续强制关闭 zero-copy / RawDraw / GPU memory buffer compositor（CEF reparent 白块约束不变）。
- Swift 侧：性能指标监视器失焦时采样间隔 1.5s → 6s，数值无可见变化时不触发 SwiftUI 刷新。
- 编译期 `static_assert` 校验全部自适应档位。

## 站点信息钻取（任务 3）

- 锁形弹窗新增页内导航：点击「证书」「网站权限」行的三角推入详情页，带返回按钮与 0.18s 推挤转场，弹窗保持 350pt 宽。
- 证书页：站点证书/颁发机构分段切换、颁发给/颁发者/序列号/有效期、SHA-256 指纹、DER 大小、复制 PEM、「完整证书查看器」次级入口（原 820×580 查看器保留）。
- 权限页：当前站点权限的查看、修改（沿用权限中心决定词汇）与删除，空状态说明，以及「在权限中心管理全部网站」入口。
- 页面导航代际变化时自动退回摘要页，避免陈旧证书上下文。

## SwiftUI 打磨（任务 2）

- 设计系统新增 `RexChromeColor`：按钮/面板/进度条的填充与描边在浅色模式改用黑色系半透明（原白色系在浅色下几乎不可见）。
- 液态玻璃按钮新增悬停高亮（含选中态加深），保持按压缩放动画。
- 工具栏、地址栏、性能芯片描边/填充改用自适应颜色。
- 标签 favicon 后备色改用 FNV-1a 稳定哈希（按站点 host），多次启动保持一致。
- 隐私盾牌与站点信息弹窗统一 `RexMetrics.popoverWidth = 350`。

## 验证与打包

- Swift Testing 全量回归与完整 CEF arm64 Debug Xcode 构建（见 CHANGELOG 对应构建记录）。
- EasyList 引擎在真实站点冒烟验证：广告请求被拦截计数，首方资源不受影响；开关即时生效。
