## 目标

1. 用 Thorium 风格运行参数提升性能。
2. 用 Swift 重做 DevTools UI，用 C++ 实现 CDP 协议核心。
3. 关闭过激广告拦截，避免站点资源被误伤。

## 完成内容

### 任务 1：Brave 功能层 + Thorium 性能层

- 新增 `ChromiumBridge/Privacy/RexPrivacyEngine.*`
  - 广告、追踪、指纹域名目录
  - 可疑脚本路径启发式
  - 主框架导航永不误伤
- 新增 `ChromiumBridge/Privacy/RexThoriumFlags.*`
  - GPU raster / Canvas OOP rasterization（默认关闭 zero-copy、RawDraw、native GPU buffers，避免 CEF 宿主白块）
  - QUIC、process-per-site、renderer 进程上限
- `RexCEFApp` 在 `OnBeforeCommandLineProcessing` 与子进程启动时统一注入参数
- 锁文件：`Chromium/feature-layer.lock.json`
- 架构说明：`Documentation/FeatureLayer.md`

说明：完整从源码编译 brave-core + Thorium 并替换 CEF 预编译包需要独立构建农场；本 beta 先交付**行为等价的可运行功能层**，源码融合路径已写入锁文件。

### 任务 2：Swift DevTools UI + C++ CDP

- UI：`Sources/RexApp/Features/DeveloperTools/*`
  - Elements / Console / Network / Sources / Performance / Memory / Application / Security
- 协议：`ChromiumBridge/DevTools/RexDevToolsProtocol.*`
  - `AddDevToolsMessageObserver`
  - `ExecuteDevToolsMethod`
  - Runtime / Network / DOM / CSS / Debugger / Overlay / Performance 等域
- 侧栏 `DeveloperToolsPanel` 改为挂载 `DeveloperToolsNativeView`

## 绘制稳定性

- 在 CEF reparent 宿主上，激进的 `RawDraw` + zero-copy 会触发跨站点大面积白块。
- v0.6.0-beta.1 最终包默认使用更稳妥的 Thorium-ish 子集：GPU raster + Canvas OOP + QUIC/process 策略。
